# 머더 미스터리 테이블

멀리 있는 친구들과 온라인으로 함께하는 머더 미스터리 사이트.

1. 테마를 고르고 이름을 적은 뒤 방에 들어가요.
2. 캐릭터를 고르고(전체 랜덤도 가능), 모두 '동의'를 누르면 시작해요. 누가 바꾸면 동의는 다시 받아요.
3. 단계마다 타이머가 돌아요. 모두 '건너뛰기'를 누르면 바로 넘어가요.
   방장(방을 만든 사람)이 '연장'을 누르면 시간이 끝나도 넘어가지 않고, 방장이 '다음 단계로'를 누를 때 넘어가요.
4. 단서 카드가 있는 테마는 카드를 테이블에 펼쳐 놓고 가져가요. 가져온 카드는 나만 보고,
   전체 공개 · 몇 명에게만 보여주기 · 넘겨주기를 할 수 있어요(테마 규칙이 막으면 그 버튼은 안 보여요). 넘겨준 카드는 더 이상 못 봐요.
5. PDF 테마는 자료가 단계마다 열려요. 공용 자료는 모두에게, 핸드아웃은 그 캐릭터를 고른 사람에게만 보여요. 엔딩·해설은 결과가 나온 뒤 모두 볼 수 있어요.
6. 밀담 단계에는 오른쪽 아래 '밀담'으로 고른 사람들끼리만 채팅해요(테마마다 최대 인원이 달라요).
7. 마지막에 투표하고 결과를 봐요. 테마에 따라 결선 투표, 최종 결정권자가 있어요.

캐릭터마다 초상화가 있고, 방 위쪽 '관계도'에서 공개된 정보로 만든 관계도와 누가 어떤 캐릭터를 맡았는지 볼 수 있어요.
일본어 자료는 자료 창에서 쪽마다 아래에 한국어 기계 번역이 자동으로 붙어요('번역 끄기'로 끌 수 있어요). 그림으로 된 쪽은 브라우저가 글자를 읽어(OCR) 번역하고, 번역한 쪽은 그 브라우저에 저장돼 다시 열면 바로 보여요.

## 연결 방식: 방장 모드

가입이나 설정 없이 바로 쓸 수 있어요. 방을 만든 사람(방장)의 브라우저가 게임을 진행하고, 친구들은 방 코드나 초대 링크로 방장에게 직접 접속해요.

- 방장은 게임이 끝날 때까지 사이트 창을 닫지 마세요. 새로고침은 괜찮아요(게임이 그대로 이어져요).
- 방장이 창을 닫으면 친구들 연결이 끊겨요. 방장이 홈 화면의 '다시 들어가기'로 돌아오면 친구들은 자동으로 다시 붙어요.
- 친구 쪽 연결이 잠깐 끊기면 자동으로 다시 연결돼요. 친구가 새로고침해도 이어져요.
- 회사·학교 와이파이처럼 막힌 인터넷에서는 연결이 안 될 수 있어요. 그럴 땐 휴대폰 데이터나 집 인터넷으로 해 보세요.

## (선택) Firebase로 바꾸기

방장이 창을 닫아도 방이 유지되길 원하면 무료 Firebase 데이터베이스를 연결할 수 있어요. `js/firebase-config.js`에 값이 들어가면 자동으로 Firebase 방식으로 바뀌어요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (이름은 아무거나, Google 애널리틱스는 꺼도 돼요)
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: 싱가포르(asia-southeast1)
   - '잠금 모드로 시작' 선택
3. 만든 데이터베이스의 **규칙** 탭에 이 저장소의 `database.rules.json` 내용을 붙여넣고 **게시**
4. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱**에서 웹 앱(`</>`) 추가 → 나오는 `firebaseConfig` 값을 `js/firebase-config.js`에 붙여넣기
   (Claude에게 그 값을 주면 대신 넣어 줘요)

## 사이트 주소 열기 (GitHub Pages)

저장소 **Settings → Pages → Branch: main / (root) → Save**.
1~2분 뒤 `https://jun2peter.github.io/Murder-Mystery/` 에서 열려요. 친구들에게는 방 안의 '링크 복사' 버튼으로 초대 링크를 보내면 돼요.

## 테마

- 테마는 `themes/` 폴더에 하나씩 있어요. 형식은 [themes/README.md](themes/README.md)에 정리했어요.
- 새 테마 자료를 Claude에게 주면 그 테마의 사용법(인원, 진행 순서와 시간, 장소, 카드, 투표 규칙)에 맞춰 만들어 넣어요.
- 테마 1 『騎上の空論』(제작: 十楽ゲスト), 테마 2 『レクイエムをもう一度』(제작: Robi嶋, 5·6·7인용), 테마 3 『MIXED』(작: おおつど, 4인용)는 원본 파일에 암호를 걸어 두었어요. 방을 만들 때 테마 암호를 한 번 넣으면 그 방 사람들은 자동으로 볼 수 있어요. 암호는 저장소에 올라가지 않아요(모든 테마 같은 암호).
- 캐릭터 초상화는 Magnific으로 만든 그림이에요(`themes/<테마>/img/`).

## 로컬에서 시험하기 (Windows)

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

http://localhost:8795 를 열고, 탭을 여러 개 띄워 한 탭에서 방을 만들고 다른 탭들은 방 코드로 들어가면 혼자서도 여러 명처럼 시험할 수 있어요. (방장 모드는 인터넷 연결이 필요해요.)
